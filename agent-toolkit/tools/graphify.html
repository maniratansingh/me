Graphify

Skill

Instruction set and reference documentation loaded directly into an agent environment.

1. What it does

Turns any codebase, including documentation, SQL schemas, and configs, into a queryable knowledge graph. Provides local deterministic AST parsing with every edge explained without requiring external vector databases.

2. Why MRPS selected it

Transforms unfamiliar or complex multi-language repositories into structured, queryable knowledge graphs for agent comprehension.

3. Tool Kind

Skill: Instruction set and reference documentation loaded directly into an agent environment.

4. Original repository

https://github.com/Graphify-Labs/graphify

5. Official documentation

https://github.com/Graphify-Labs/graphify#readme

6. Author and license

Created by Graphify Labs under the Apache-2.0 license.

7. Installation

uv tool install graphifyy && graphify install

8. When the AI should use it

Use when exploring architecture, tracing complex cross-file dependency graphs, or onboarding to a new codebase.

9. When the AI should not use it

Do not use as a fast single-file syntax linter or typechecker.

10. What the AI must not do

  • Before you invoke anything, state what you intend to do and why. Do not act until the user confirms. If a rule is ambiguous, ask — do not guess.
  • Graphify is an architectural analysis skill; it does not produce scan issue lists for the launcher.
  • Run analysis strictly within the project boundary and store outputs in graphify-out/.
  • Do not alter source code or configuration files during graph generation.
