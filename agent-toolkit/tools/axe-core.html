axe-core

Library

Reusable software package imported or integrated into application code.

1. What it does

The standard automated accessibility engine that evaluates web applications against WCAG 2.0, 2.1, and 2.2 Level A and AA standards with zero false positives.

2. Why MRPS selected it

The definitive benchmark for programmatic, rule-based accessibility violation detection.

3. Tool Kind

Library: Reusable software package imported or integrated into application code.

4. Original repository

https://github.com/dequelabs/axe-core

5. Official documentation

https://github.com/dequelabs/axe-core#readme

6. Author and license

Created by Deque Systems under the MPL-2.0 license.

7. Installation

npm install -D @axe-core/cli

8. When the AI should use it

Use when auditing web pages, templates, and rendered components for WCAG 2.1/2.2 AA accessibility violations, color contrast, and ARIA roles.

9. When the AI should not use it

Do not assume 100% test coverage from automated checks; manual keyboard and screen reader verification is still required.

10. What the AI must not do

  • Before you invoke anything, state what you intend to do and why. Do not act until the user confirms. If a rule is ambiguous, ask — do not guess.
  • Group and report findings strictly by impact severity (critical, serious, moderate, minor).
  • Do not modify source templates or ARIA attributes without presenting the proposed changes and obtaining user confirmation.
  • Clearly differentiate between automated rule violations and warnings requiring manual review.
