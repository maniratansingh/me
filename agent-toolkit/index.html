MRPS Agent Toolkit · Public

Tools for better AI development.

A curated collection of modern, verified open-source tools and agent skills for coding agents. This is a directory and connector — not a fork or replacement for the projects it lists.

How this works: These represent the latest tools used across UI/UX, accessibility, security, testing, and code analysis. You can use any of them independently from their respective creators by clicking their direct GitHub links.

If you want a unified workflow, running this toolkit connects and coordinates them together under strict read-only safety rules — auditing your project without modifying your source code, configuration, or manifests.
