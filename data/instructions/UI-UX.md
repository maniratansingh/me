# UI/UX Instructions — MRPS Agent Toolkit

## Overview
Guidelines for inspecting, auditing, and refining user interfaces, design system compliance, and visual polish.

## Category & Tools
- **Tools**: `impeccable` (`kind: skill`)
- **Category**: `ui-ux`

## When to Reach for What
- Reach for `impeccable` to evaluate visual hierarchy, aesthetic balance, spacing rhythm, responsive layout integrity, and typography choices.

## The Inspect → Critique → Recommend → Fix Ladder
1. **Inspect**: Review templates, CSS/SCSS/Tailwind stylesheets, and component markup without altering code.
2. **Critique**: Identify layout shifts, arbitrary margin/padding values, contrast issues, or missing interactive states.
3. **Recommend**: Provide exact design tokens, CSS variables, or class recommendations to resolve aesthetic shortcomings.
4. **Fix**: Update component styles and markup only when the user confirms with explicit "fix" instructions.

## Tool Guidance: Impeccable
### When to use
Use during UI design reviews, component refactoring, landing page audits, or when addressing user feedback on layout polish and anti-slop standards.

### When NOT to use
Do not use for raw functional unit testing, backend logic validation, or low-level binary analysis.
