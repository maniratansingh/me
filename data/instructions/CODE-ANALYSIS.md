# Code Analysis Instructions — MRPS Agent Toolkit

## Overview
Guidelines for architectural exploration, static code analysis, semantic knowledge graph generation, and dependency relationship mapping.

## Category & Tools
- **Tools**: `graphify` (`kind: skill`)
- **Category**: `code-analysis`

## When to Reach for What
- Reach for `graphify` to convert an unfamiliar codebase into a queryable knowledge graph with deterministic AST parsing, architectural reports, and relation mapping. Note: Graphify is an exploration skill invoked directly; it does not produce scan finding lists.
- For code checks (linting/typechecking) inside the launcher runner, projects rely on their declared language tooling (`tsc`, `eslint`, `ruff`, `mypy`, `clippy`).

## The Inspect → Critique → Recommend → Fix Ladder
1. **Inspect**: Parse ASTs, generate relationship graphs, and inspect symbol usage without touching source trees.
2. **Critique**: Pinpoint circular dependencies, monolithic modules, dead code paths, and architectural debt.
3. **Recommend**: Suggest modular refactoring plans or interface boundaries.
4. **Fix**: Refactor files or reorganize directory layouts only under direct user instruction.

## Tool Guidance: Graphify
### When to use
Use when onboarding to a complex repository, analyzing cross-module dependencies, or mapping documentation and SQL schemas into a connected graph.
### When NOT to use
Do not use as a fast line-by-line syntax linter.
### Example Invocation
```bash
uv tool install graphifyy && graphify install
# Run /graphify . in your agent
```
